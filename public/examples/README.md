# Public Demo sprites

`mochi-sprout.png` and `plush-cloud.png` are original synthetic mascot images generated for this public candidate on 2026-09-29. Neither uses a user portrait or a private photo as reference. Both have transparent backgrounds and are **fixed Demo results**, not the output of the app's live Seedream API.

`tests/samples/pet-cat.png` is a separate synthetic cat photo generated for browser tests of upload and local background removal. It depicts no real user's pet.
